## 1. Propósito del Proyecto
**NeoBlender Web 3D + MCP Bridge** es un estudio de modelado y renderizado 3D hiperrealista basado en navegador (Three.js r160 + WebGL2) diseñado para ser **co-operado por humanos e Inteligencias Artificiales en tiempo real** mediante el **Model Context Protocol (MCP)**.

## 2. Capacidades de Visión y Control para IAs (`window.MCP_BRIDGE`)
El motor expone una interfaz JSON-RPC 2.0 tanto en el DOM (`window.MCP_BRIDGE.handleJsonRpc(payload)`) como vía WebSocket (`ws://localhost:8765`).

### Herramientas MCP Expuestas (`tools/list`):
1. **`mcp_get_scene_graph`**
   - **Propósito:** Permite a la IA inspeccionar la totalidad de la escena (posición de cámara, exposición HDR, lista de mallas, geometrías, transformaciones XYZ y parámetros PBR).
2. **`mcp_capture_viewport`**
   - **Propósito:** Devuelve un snapshot `{ mimeType: "image/png", dataUrl: "data:image/png;base64,..." }` del render actual.
   - **Nota técnica:** El `WebGLRenderer` tiene `preserveDrawingBuffer: true` activado para garantizar capturas limpias sin frames en negro.
3. **`mcp_spawn_pbr_mesh`**
   - **Parámetros:** `{ type, name, color, metalness, roughness, clearcoat, transmission, ior, x, y, z }`.
   - **Propósito:** Crea objetos con `MeshPhysicalMaterial` de forma declarativa.
4. **`mcp_execute_three_code`**
   - **Parámetros:** `{ code: "string con código JS" }`.
   - **Propósito:** Permite a una IA ejecutar generación procedural avanzada, booleanas, modificadores de vértices o animaciones teniendo acceso directo a `(THREE, scene, app)`.

## 3. Estándares de Hiperrealismo (PBR)
Cuando una IA genere nuevos modelos o materiales en este proyecto, debe priorizar:
- Uso de **`THREE.MeshPhysicalMaterial`** sobre `MeshStandardMaterial`.
- Configuración de **`clearcoat`**, **`transmission`** e **`ior`** (Índice de Refracción entre `1.0` y `2.33`) para materiales dieléctricos, vidrios, resinas, arcillas húmedas o metales lacados.
- Geometrías con subdivisión suficiente (mínimo 64 segmentos en superficies curvas) o mapas normales procedurales.

- [ ] **Fase 4:** Implementar modo de escultura de vértices (Sculpt Mode) y modificadores (Subdivision Surface, Array, Boolean).
- [ ] **Fase 5:** Crear script `mcp-server.js` (Node.js) para conectar Claude Desktop / Cursor directamente al WebSocket del navegador.
